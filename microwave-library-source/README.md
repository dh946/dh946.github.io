# 光生微波文献排名项目文件

本目录保存该静态网站的代码与数据库副本。线上只读页面位于仓库的 `microwave-library/` 目录，地址为 https://dh946.github.io/microwave-library/ 。

论文 PDF、Node 依赖和临时文件未上传。完整的本地文献维护环境仍以作者电脑上的项目目录为准；请在本地通过“启动网页.bat”添加 PDF、核验记录并更新排名。完成后需将更新的 `dist/papers-data.js`（若页面代码有变化，再包含 `dist/index.html`）同步到仓库 `microwave-library/` 目录，提交后线上页面才会更新。

网页源文件及数据可在本目录的 `dist/`、`data/`、`scripts/` 中查看。
